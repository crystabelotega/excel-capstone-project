# excel-capstone-project
An Excel capstone project analysing Titanic passenger survival patterns, identifying high-vulnerability groups, and generating data-driven insights to support better safety and evacuation planning.

## Project Overview
The aim is to identify factors associated with survival outcomes, highlight vulnerable passenger groups, and generate data-driven recommendations for improved and modern safety and evacuation planning.

## Business Problem
This project investigates how passenger class, sex, age, fare, family size, and port of embarkation relate to survival outcomes.

## Dataset Description
- Dataset: Titanic passenger dataset
- Scope: 418 passenger records
- Tools: Microsoft Excel, Power Query, PivotTables and Excel dashboards.

- ## Key Findings
- Overall survival rate: 36.36%.
- Total non-survivors: 266.
- Third Class recorded the highest survivor count, with 72 passengers.
- Survival outcomes varied across passenger demographics.

- ## Recommendations
- Promote equal access to emergency safety procedures irrespective passenger classes.
- Prioritise inclusive evacuation planning for vulnerable passenger groups like the Elders.
- Use passenger characteristics to inform emergency preparedness.
